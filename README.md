# 🏋️ FitLog — Workout Library

> **Train with intent. Log every set.**

FitLog is a modern workout library and planning web app built with **Next.js**. Users can explore workouts, view details, create a daily workout plan, and save exercises for later.

## ✨ Features

- 🏋️ Browse workout library
- 🔎 View detailed workout information
- 📋 Create and manage today's workout plan
- ❤️ Save workouts for later
- ✅ Mark workouts as completed
- ❌ Remove workouts from the plan
- 🔃 Sort workouts by duration, calories, or rating
- 💾 Persist plan and saved workouts with localStorage
- 📱 Fully responsive design
- 🔔 Toast notifications for user actions

## 🛠️ Technologies

- **Next.js**
- **React**
- **TypeScript**
- **Tailwind CSS**
- **Ant Design**
- **Lucide React**
- **REST API**
- **LocalStorage**

## 📂 Pages

- `/` — Workout Library
- `/workout/[id]` — Workout Details
- `/my-plan` — My Plan & Saved Workouts
- `404` — Custom Not Found Page

## 🚀 Getting Started

```bash
git clone https://github.com/your-username/fitlog.git
cd fitlog
npm install
npm run dev
```

Open **http://localhost:3000** in your browser.
